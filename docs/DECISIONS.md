# Decision log

Append-only. Any change to truth definitions, thresholds, scoring or binning after a batch exists needs a dated entry here and a new pre-registration.

## 2026-10-22

- **D-001 Manipulated variable.** Literature density per gene, holding task and dataset fixed. Reason: post-cutoff designs saturate (BioStudyBench best closed model 94.7%) and planted faults saturated in planted-fault-bench.
- **D-002 Domain.** Genes over neuroimaging: measurable density for ~10,000 uniformly perturbed genes; neuro entities lack a clean density axis.
- **D-003 Primary dataset.** Zhu et al. 2026 CD4+ T-cell genome-scale CRISPRi Perturb-seq: donor replication (truth from held-out donors) and three conditions (context shift). Virtual Cell Challenge 2026 data as contingent replication.
- **D-004 Density measure.** Fractional gene2pubmed counts, papers linking >100 genes dropped, Entrez IDs, PMID cutoff at the earliest evaluated model's training cutoff.
- **D-005 Phase 0 truth.** Combined-donor differential-expression results with fixed thresholds as provisional truth; held-out-donor truth starts in Phase 1.
- **D-006 Integrity.** Batches require a filled, committed and pushed pre-registration; one batch per pre-registration commit unless a reason is recorded in the ledger; only aggregates are committed; data, runs and truth live outside the repository.
- **D-007 Zero-paper bin.** With `density.zero_bin: true`, QC-passing genes with no gene2pubmed-linked papers before the PMID cutoff (after the >100-gene filter) form bin 0; the remaining genes get `density.n_bins` quantile bins of log density, numbered 1..n_bins, with ties sharing a bin. Reason: zero-paper genes all tie at the lowest density, so plain quantiles merge them into a bin of variable size and blur the least-studied end. Decided before any batch and before the gene table was built.
- **D-008 Stray records in the PMID cutoff.** The cutoff is the smallest PMID entered on the cutoff day after ignoring PMIDs more than `density.stray_pmid_gap` (1,000,000) below that day's median; the number ignored is recorded in `density_meta.json`. Reason: on 2026-07-01 one old record (PMID 25905264) carries that entry date while the other 6,424 start at 42378835, and taking the plain minimum would drop about eleven years of papers. Decided before any batch.
- **D-009 No keep_test_genes requirement.** `keep_test_genes` appears only in the pseudobulk object; the DE results file contains only DE-eligible perturbations (11,526 targets vs the paper's 11,527 tested genes), so the flag is redundant and `obs.flags_require_true` is empty. `ontarget_significant` (on-target knockdown significant at 10% FDR, per perturbation × condition) is reported per density bin in the feasibility report as a covariate and is not used for filtering. Decided before any batch.
- **D-010 Zero-paper bin dropped (supersedes D-007).** `density.zero_bin` is false: bins are 5 quintiles of log density over all QC-passing genes, with zero-paper genes in the lowest quintile. Reason: bin 0 (123 zero-paper genes) had only 3 "decreased" and 13 "increased" candidate questions on the readout panel, too few for label-balanced sampling. Decided from candidate counts only, before any model call. IL17A is removed from `probe.readout_panel` because it is not measured in the DE file.

## 2026-10-23

- **D-011 Sol added to Phase 0.** The pre-registration (commit 611291f) is amended before any batch to evaluate `sol-6.1-cli` alongside `opus-5.5-cli`. The Codex CLI runs with shell, unified exec, apps, plugins, browser, image and multi-agent tools disabled, web search off, no MCP servers, reasoning effort xhigh and a separate `CODEX_HOME`; smoke tests on 2026-10-23 returned the requested JSON and confirmed no file access.
- **D-012 Density cutoff moved to 2026-05-01.** With Sol added (D-011), the earliest evaluated-model knowledge cutoff is GPT-6.1 Sol's, 2026-04-30 (as stated by the investigator), so `density.cutoff_date` is 2026-05-01 per D-004 and the PMID cutoff is re-resolved to 42060948 (5 stray records ignored, D-008). At this cutoff the zero-paper bin was re-checked: 124 genes with 3 "decreased" and 13 "increased" candidates, still below quota, so the 5-quintile split (D-010) stands. All 5 bins meet the 120-question quota. Decided from candidate counts only, before any model call.
